# Prags.pov — Portfolio of Pragati Srivastava

[![CI](https://github.com/nileshcf/content-creator/actions/workflows/ci.yml/badge.svg)](https://github.com/nileshcf/content-creator/actions/workflows/ci.yml)

A cinematic, immersive 3D portfolio for a content creator & digital media manager.
Dark noir aesthetic, liquid-metal WebGL hero, film grain, smooth momentum scrolling.

## Stack

| Layer | Tech |
| --- | --- |
| Framework | Next.js 16 (App Router, Turbopack) |
| Styling | Tailwind CSS v4 (CSS-first `@theme` tokens) |
| 3D | Three.js + React Three Fiber + drei |
| Animation | Framer Motion 12 |
| Scrolling | Lenis |
| Type | Syne (display) + Inter (body) via `next/font` |

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
```

## Deploy to Vercel

1. Push this repo to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repo.
3. Framework preset auto-detects **Next.js** — no config needed. Deploy.

Or from the CLI:

```bash
npx vercel
```

### Environment variables

| Variable | Required | Purpose |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | No | Canonical URL once a custom domain is attached (e.g. `https://pragspov.com`). Falls back to the Vercel deployment URL automatically. Used for Open Graph, sitemap and robots. |

## Edit the content

Everything about Pragati — bio, socials, experience, showcase cards, skills,
education, certifications, marquee words — lives in one file:

```
src/lib/data.ts
```

Change the text there and the whole site updates. Design tokens (colors, fonts,
animations) live in `src/app/globals.css` under `@theme`.

## Structure

```
src/
├─ app/            layout (fonts + metadata), page, global theme
├─ lib/data.ts     ← all site content
└─ components/
   ├─ three/HeroScene.tsx   WebGL blob, halo, particle field, parallax rig
   ├─ Hero.tsx              cinematic intro
   ├─ Navbar.tsx            glass nav + mobile sheet
   ├─ Marquee.tsx           infinite skill strip
   ├─ About.tsx             story + animated counters + identity card
   ├─ Experience.tsx        glowing timeline
   ├─ Showcase.tsx          3D-tilt platform cards
   ├─ Skills.tsx            toolkit + education + certifications
   ├─ Contact.tsx           roll-credits finale + footer
   ├─ Cursor.tsx            custom cursor (desktop only)
   ├─ SmoothScroll.tsx      Lenis momentum scrolling
   └─ Reveal.tsx            scroll-reveal helper
```

## Production notes

- **SEO** — Open Graph + Twitter cards (using the portrait), `sitemap.xml`,
  `robots.txt` and a PWA manifest are generated by route handlers in `src/app/`.
- **Security** — `nosniff`, `X-Frame-Options: DENY`, referrer and permissions
  policies set globally in `next.config.ts`.
- **Images** — served as AVIF/WebP via `next/image`.
- **Accessibility** — respects `prefers-reduced-motion` (smooth scroll, cursor,
  grain and animations all stand down), semantic landmarks, keyboard-reachable
  links, `aria-label`s on icon links.
- **CI** — GitHub Actions lints and builds every push/PR to `main`.

`scripts/` contains dev-only puppeteer screenshot helpers — not part of the build.
